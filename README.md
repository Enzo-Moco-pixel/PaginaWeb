# PaginaWeb
DICAS PARA ECONOMIZAR

Esse trabalho foi feito para a disciplina de Educação Digital, com o objetivo de apresentar um tema sobre economia e educação financeira.

Esse site pretende mostrar um pouco mais sobre como economizar dinheiro, controlar os gastos e organizar melhor as finanças, utilizando textos, imagens e um vídeo para facilitar a compreensão.

Eu aprendi mais sobre economia e organização financeira com esse trabalho e achei importante conhecer melhor esse tema.

O maior desafio na criação do site foi fazer o botão de like funcionar corretamente utilizando JavaScript e o momento de estilizar o CSS.

Nesse trabalho, foram utilizadas imagens para representar o tema de economia e ajudar a entender melhor o conteúdo.

Esse site foi feito apenas por mim. Algumas pesquisas foram necessárias para apoio e para completar o site, mas de resto tudo foi feito exclusivamente por mim.

As pesquisas foram feitas principalmente no Google e no YouTube, porém foi utilizado pouco conteúdo dessas pesquisas, servindo principalmente como apoio durante a criação.

A maioria das tags utilizadas foram retiradas dos conteúdos do Alura e algumas do Classroom pela professora.

Também foram utilizados conhecimentos aprendidos durante as aulas das professora e das aulas do Alura.

Esse trabalho e esse site foram feitos exclusivamente para a disciplina de Educação Digital, com o objetivo de apresentar informações e dicas sobre economia e como economizar dinheiro.
